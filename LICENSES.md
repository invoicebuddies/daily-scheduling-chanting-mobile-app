# Bundled sound licenses

## Built-in chimes (`core/player/src/main/res/raw/`)

The following files were **synthesized in code** for this project (additive
sine partials with exponential decay, mimicking struck bells / singing bowls —
no source recordings, so no third-party license applies):

| File | Description |
|---|---|
| `builtin_morning_bell.wav` | Bell tone, 528 Hz fundamental, 3 s decay |
| `builtin_temple_bell.wav` | Deeper bell tone, 440 Hz fundamental, 4 s decay |
| `builtin_singing_bowl.wav` | Bowl-like tone, 396 Hz fundamental with emphasized 2.76× partial, 4 s decay |
| `fallback_chime.wav` | Same family as the morning bell (528 Hz); used when every user-picked sound fails to play |

They are contributed to the project under the same license as the project
itself; treat them as CC0-equivalent for reuse.
