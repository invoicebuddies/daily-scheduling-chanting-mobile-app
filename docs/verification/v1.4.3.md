The QS tile (verified) shares the same start/stop path, `WidgetBridge.requestUpdate` fires on every session start/stop, and no widget code changed since v1.4.2.
- **R13 (compose window):** a prefilled Gmail compose (To + exact subject visible) needs a signed-in Google account, which the emulator does not have. The Send button verifiably launches Gmail via the mailto intent; the exact subject and body construction are pinned by `FeedbackComposerTest`. The copy fallback was verified end-to-end with Gmail disabled.
- **R14 (update card):** can only appear on a build older than the GitHub latest release; v1.4.3 was the newest until it was published. Decision logic covered by `UpdatePromptLogic`/`VersionComparatorTest`.
- **Scene art observation (not a failure):** Lotus/Temple dawn/Abstract light render inside a 210 dp centred vignette in the header (Monk is full-bleed), so they look subtle — this matches the v1.4.2 design and its shipped screenshots.
