Screenshots for the README
==========================

Add four phone screenshots to this folder with these exact filenames so the
README image row renders:

  home.png    - the schedule list: greeting header, next-session hero,
                at least one schedule card
  edit.png    - the edit screen: time dial (or routine steps), sounds row
  ringing.png - the ringing page during playback (SNOOZE / STOP visible)
  stats.png   - the stats screen with some session history

Tips:
- Use the light theme, English, and a clean device (no debug overlays).
- ~1080x2400 portrait PNGs, cropped to the app (no launcher background).
- Keep each file under ~500 KB.
