# Translations

Chanting Buddy ships with every user-facing string in resources. Built-in
chime names (Morning bell, Temple bell, Singing bowl) are proper-noun product
names and stay untranslated in every locale.

## Shipped locales

| Locale | Language | Notes |
|---|---|---|
| `en` | English | Source strings |
| `zh-rCN` | Simplified Chinese | Community-reviewed style |
| `ms` | Malay | Community-reviewed style |
| `th` | Thai | Machine-assisted |
| `my` | Burmese (Myanmar) | Machine-assisted |
| `si` | Sinhala | Machine-assisted |

## th / my / si need native eyes

The Thai, Burmese, and Sinhala translations were produced with machine
assistance and have **not** been reviewed by a native speaker. Wording is
deliberately calm and simple, and Buddhist terms follow common usage
(Thai: วันพระ for Uposatha days, สวดมนต์ for chanting; Burmese: ဥပုသ်နေ့,
ပရိတ်ရွတ်; Sinhala: පොහොය, පිරිත් / ගාථා), but they will surely contain
unnatural phrasing.

**Found something wrong or awkward?** Please tell us — in the app:

Settings → About → **Support & feedback**, topic **"Translation issue"**,
and name the locale (e.g. "Burmese") plus the screen. That email goes
straight to the developer.

Corrections are welcome for the reviewed locales too.
